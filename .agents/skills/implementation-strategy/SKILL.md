# Implementation Strategy

- Read `AGENTS.md`, relevant docs, configuration, entry points, and tests before editing.
- State goal, success criteria, assumptions, ambiguities, tradeoffs, simpler alternative, files,
  silent-failure risks, and verification.
- Keep the template generic. Do not invent scientific scope, formulas, authorities, or claims.
- Prefer the smallest complete change and stop at an approval boundary.
