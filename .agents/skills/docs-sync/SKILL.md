# Documentation Sync

- Update behavior and documentation together.
- Check README, scope, validation, privacy, decisions, maintenance, citation, changelog, UI copy,
  and dependency provenance.
- Preserve `AUTHOR ACTION REQUIRED` prompts until authoritative values exist.
- Keep claims within validated functionality; engineering tests do not establish scientific or
  clinical validity.
