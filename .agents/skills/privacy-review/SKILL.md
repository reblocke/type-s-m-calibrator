# Privacy Review

- Treat scientific or clinical input as potentially sensitive.
- Keep computation client-side with no backend, analytics, persistence, cookies, or hidden state.
- Do not put input values in URLs, logs, network requests, committed fixtures, or screenshots.
- Use synthetic fixtures and document explicit user-triggered local exports.
- Stop and document data flow, retention, access, and compliance before adding storage or sharing.
